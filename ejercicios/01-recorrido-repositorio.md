# Bloque 1 · Recorrido por un repositorio real (5:00–5:07 p. m.)

## Objetivo
Reconocer en un repositorio real las cuatro piezas que vas a practicar: historial de commits, rama, pull request y URL publicada.

## Pasos
1. Escribe en el chat si ya tienes tu URL de GitHub Pages: "Sí" o "Todavía no".
2. Observa el recorrido. Ubica dónde está el historial (**Commits**), la lista de ramas (**Branches**), la pestaña **Pull requests** y la URL publicada.
3. Anota una pregunta si algo no queda claro. Hay espacio para preguntas al final.

## Resultado esperado
Sabes dónde encontrar el historial, las ramas y los PR en cualquier repositorio.

## Enlace de evidencia
Este bloque no tiene evidencia propia. Prepara el terreno para los resultados 2 a 5.

## Variante asíncrona (grabación)
Mira el capítulo 1. Luego abre esta plantilla y encuentra por tu cuenta **Commits**, **Branches** y **Pull requests** en la parte superior del repositorio. En celular, la pestaña **Pull requests** puede estar en el menú de pestañas deslizable.
